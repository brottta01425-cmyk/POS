# v17.3 Bluetooth / Wi-Fi Auto Print

Changes:
- Cash and Online payment buttons now automatically print the receipt after Supabase confirms payment.
- Buttons are labelled CASH + PRINT / ONLINE + PRINT.
- Added a Test Print button to Billing printer settings.
- The Test Print button is enabled only after Test / Connect succeeds.
- Manual PRINT and Billing History REPRINT are still available.

Android Bluetooth Classic/SPP:
1. Pair printer in Android Settings.
2. Billing -> Bluetooth.
3. Select paired printer.
4. Tap Test / Connect.
5. Confirm green Connected badge.
6. Tap Test Print.
7. Collect Payment -> Cash + Print / Online + Print.

If Test / Connect works but Test Print fails, the printer may use a non-standard Bluetooth SPP service or ESC/POS command set.
