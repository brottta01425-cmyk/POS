## Takeaway / Parcel token
Only Takeaway / Parcel orders receive a token number.

Receipt order:
- Type: TAKEAWAY / PARCEL
- Source: DIRECT / ZOMATO ORDER
- Token No: 1, 2, 3...

The token counter is atomic in Supabase and uses Asia/Kolkata calendar dates.
At the start of each new day the counter effectively resets to 0, so the first new takeaway order receives Token 1.

Run `SUPABASE_V18_1_TOKEN_MIGRATION.sql` once in Supabase SQL Editor.

Dine-in orders do not receive or print a token number.
