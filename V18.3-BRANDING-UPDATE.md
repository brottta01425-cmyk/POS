# Brottta POS v18.3 Branding Update

Changes:
- Printed receipt footer is centered.
- Only `Powered by Highloops` is bold.
- `www.highloops.in` remains normal weight.
- Website favicon uses the supplied BROTTTA wordmark image.
- Android launcher icon uses the supplied square BROTTTA illustrated image.
- Android build setup automatically copies the launcher icons after Capacitor creates/syncs the Android project.
- Capacitor config uses `capacitor.config.json` to avoid TypeScript config parsing issues.

For an existing Android project:
1. `npm install`
2. `npm run android:sync`
3. `npm run android:open`
4. Build the updated APK with the same app ID and the same signing keystore.
5. Install the APK over the existing restaurant app; do not uninstall the current app.

For the website, commit/push the changed files to the Git branch connected to Vercel.
