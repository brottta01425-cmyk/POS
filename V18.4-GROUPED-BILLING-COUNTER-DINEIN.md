# Brottta POS v18.4

## 1. Club repeated orders into one bill

Billing is now based on the selected seating group, not on each order ticket.

Examples:

### Entire Table
Table 4 - Entire Table:
- Order 1
- Order 2
- Order 3

When `ENTIRE TABLE` is selected for billing, all three open orders are sent as ONE bill.

### Chair group
Table 4 - CH-1&2:
- Order 1
- Order 2
- Order 3

All open CH-1&2 orders are clubbed into ONE CH-1&2 bill.

Table 4 - CH-3&4 remains a separate bill.

The cashier sees one card per bill group, can print the combined items/total, collect one payment, or delete the complete unpaid bill.

Billing History also clubs the paid order tickets that were paid together.

## 2. Counter Dine-In

The cashier order selector is now:
- Takeaway
- Dine-In

`Dine-In` is for customers ordering/paying directly at the cashier.

When Dine-In is selected:
- It is classified as Dine-In for dashboard/analytics.
- It goes directly to Billing.
- It does NOT go to Kitchen.
- It does NOT receive a Takeaway token.
- Receipt prints `DINE IN` and `Service: COUNTER DINE-IN`.

Takeaway continues to:
- receive a daily token
- go to Kitchen
- then go to Billing.
