# Brottta POS v18.5.2

Counter Dine-In direct billing is now a complete immediate flow:

1. Cashier selects `Dine-In`.
2. Adds items.
3. Taps `CREATE DIRECT BILL`.
4. A payment popup opens immediately.
5. Cashier chooses:
   - CASH + PRINT
   - ONLINE + PRINT
6. Payment is saved to Supabase.
7. Receipt prints.
8. Ordered-item cart, customer fields and source selection reset automatically.
9. The order never goes to Kitchen.

No new Supabase migration is required beyond the existing v18.4 migration.
