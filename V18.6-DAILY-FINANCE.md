# Brottta POS v18.6 — Daily Finance

## Attendance → automatic salary expense
Attendance now has a final Submit button.

Flow:
1. Select date.
2. Mark every active employee.
3. Salary Preview is calculated:
   - PRESENT = 100% of per-day salary
   - HALF_DAY = 50%
   - ABSENT / LEAVE = 0
4. Tap `SUBMIT ATTENDANCE & ADD SALARY EXPENSE`.
5. One automatic salary expense is created for that date.
6. Re-submitting the same date updates the same salary expense instead of creating a duplicate.

## Expenses
Expenses now show a selected day's:
- Staff Salary
- Other Expenses
- Total Expense

Manual expenses can be added directly to the selected date.

## Sales Adjustment
Dashboard shows explicitly:
- Total Sales (raw POS paid sales)
- Adjustment
- Adjusted Sales = Total Sales + Adjustment
- Total Expenses
- Profit / Day Total = Adjusted Sales - Total Expenses

Adjustment can be positive or negative and includes a note/reason.
For a date range, the Dashboard sums each day's saved adjustment.

## Daily Profit
Dashboard has a daily breakdown:
Date | Total Sales | Adjustment | Adjusted Sales | Expenses | Profit

Analytics profit also uses Adjusted Sales.

## Required Supabase migration
Run `SUPABASE_V18_6_DAILY_FINANCE_MIGRATION.sql` once.

## Formula
`Adjusted Sales = Total Sales + Adjustment`

`Profit / Day Total = Adjusted Sales - Total Expenses`

A negative adjustment reduces sales; a positive adjustment increases sales.
